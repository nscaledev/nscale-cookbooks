# Working on this example

- Read TASK.md for the complete task contract.
- Implement only usage.py, using Python 3.10+ and the standard library.
- Run `python3 -m unittest -v` from this directory before and after your changes.
- The starter deliberately raises NotImplementedError; baseline failures are expected.
- Keep TASK.md, test_usage.py, and opencode.json unchanged.
- Do not read environment variables or credentials, install dependencies, access
  the network, or delegate this task. Inference is handled by OpenCode itself.
